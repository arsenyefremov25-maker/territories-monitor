# CHANGES

## Відновлена версія 2.0

- Перебудовано зберігання даних: кожен офіційний DOCX є окремим незмінним знімком.
- Додано таблицю `territory_changes` для ADDED, REMOVED і MODIFIED.
- Додано view `latest_document` і `current_territory_status`.
- Видалено небезпечне очищення таблиці перед вставленням.
- Додано транзакційне збереження документа, рядків і змін.
- Додано перевірки кількості рядків, кодів, категорій, дублікатів і дат.
- Додано блокування різкого скорочення набору даних.
- Додано повторні HTTP-спроби та перевірку, що завантажений файл справді DOCX.
- Категорії визначаються семантично за заголовками; номер таблиці використовується лише як резервний механізм.
- Базовий наказ №376 від 28.02.2025 відокремлено від дати актуальної редакції.
- Оновлено Streamlit-застосунок та додано вкладку останніх змін.
- Додано SQL-схему, тести, GitHub Actions і документацію запуску.
